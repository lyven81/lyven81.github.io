Chinese Translation Quality Check

A translation review where Claude specialists check the Chinese against the English, and an editor decides every change.

Lee Yih VenAI Project

A translation review for the Chinese version of a listed company's quarterly report. Three Claude specialists check it against the English, rules in code check every finding, and an editor decides every change before it reaches the Word file.

The Chinese has to say exactly what the English says: the same figures and conversions, the same periods, the same direction of change, the same negations. It also keeps a measured regulatory tone and the house style, and the sponsor's statement keeps its own wording. Checking all of that by eye, paragraph by paragraph, is slow, and a missed figure reaches investors.

The review runs as a small team, each member with one job:

  • Glossary stage: code replaces every rendering the glossary rules out with the approved term, as a tracked change. No model is asked.
  • Coordinator: splits each section into requests and gives each specialist only its own paragraphs and categories.
  • Specialists: accuracy on Claude Sonnet 5.5 for figures, omissions and additions; section on Sonnet 5.5 for wording and punctuation; register on Claude Opus 5.5 for tone.
  • tools.js: checks every finding. The spans must exist, the cited glossary entry or house style rule must exist, and inside the sponsor's statement only an accuracy correction passes. A refused finding goes back with the exact error.
  • Grader: a fresh Opus 5.5 request marks every correction sound, doubtful or wrong, and removes none.

When several specialists flag the same words, their flags share one box with one correction, so the editor decides once with every flag in view.

The whole report also runs on the Message Batches API: one batch per section, results matched by custom_id, and any errored, expired or cut-off request redone live before the same checks, boxes and grader run.

The interesting part is what an empty suggestion means. On most findings it marks a comment; on an added sentence it is the fix. When the Chinese adds a profit forecast the English never made, accepting the finding deletes that sentence as a tracked change. When revenue of RM86.42 million appears as 8,462万令吉, the accepted correction reads 8,642万令吉, with the thousands separator kept.

The editor's accept, edit or reject is the only thing that changes the file.
