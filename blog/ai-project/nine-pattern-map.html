9-Pattern Map (synthesis)

Nine production AI architecture patterns and when each one fits.

Nine architecture patterns that keep showing up across production AI apps for SMEs — and when each one is actually the right fit.

  1. Multi-Agent Orchestration (ADK + A2A) — when failure isolation and independent scaling matter. Each agent on its own Cloud Run service.
  2. Browser-Native Agent Tools (WebMCP) — when you want to be discoverable to AI shopping agents. Storefront exposes typed tools via navigator.modelContext.
  3. Real-Time Voice AI — when typing is the friction. Gemini Live + WebSocket + bidirectional PCM streaming.
  4. MCP — when the LLM needs to ground its answers in real data without hallucinating SQL. Typed tools over the database.
  5. RAG — when the answer lives in a corpus of documents too big to stuff in the prompt.
  6. Agentic — when the task is multi-step and the path varies based on intermediate results.
  7. Hybrid / Token-Lean — when cost per call dominates. Plain LLM + structured output + a few functions, no framework.
  8. LLM Chatbots — when conversation is the whole product. No tools, no state, just prompt-driven Q&A.
  9. RPA Pipelines — when the workflow is deterministic. Scheduled LLM calls with structured output. Cron + Cloud Run.

The honest takeaway from building across all nine: most "AI app" requests fall into Hybrid (#7) or RPA (#9). The exotic patterns get all the press. They're not what most businesses actually need.

The skill that matters isn't picking the fanciest pattern. It's reading the problem and reaching for the simplest one that works for it.
