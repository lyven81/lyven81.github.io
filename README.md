## What this is

A single-page personal site that links Lee Yih Ven's three working properties — the consultancy, the analytics archive, and the AI project archive — into one place. Built around the principle that every project is public, so prospects can verify the work themselves.

## About

Lee Yih Ven runs **Pau Analytics**, a one-person data analytics consultancy serving Malaysian F&B, retail, and e-commerce SMEs. The work is deliberately public — case studies, AI builds, methods, and learnings all ship in the open.

Three pillars:
- **Consult** — direct consulting through Pau Analytics
- **Analyze** — case study archive of real SME problems solved with data
- **Build** — AI assistants made for how SMEs actually work

## How it's built

- Single static HTML page, no build step
- Inline CSS, no framework
- Google Fonts: Inter + Playfair Display
- Hosted on GitHub Pages (auto-publish from `main`)

## Run locally

Just open `index.html` in any browser — no server, no dependencies. To preview as it would appear when shared:

```bash
git clone https://github.com/lyven81/lyven81.github.io.git
cd lyven81.github.io
# Open index.html in your browser
```

## Updating the site

```bash
# After editing index.html or profile.jpg
git add index.html
git commit -m "Update <what changed>"
git push
```

GitHub Pages rebuilds and redeploys within ~1 minute of each push.
